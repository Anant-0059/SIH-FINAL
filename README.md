# Delhi NCR Air Quality Intelligence Dashboard

The application source code, ML pipeline, datasets, and scripts are located in `delhi-aqi-dashboard/`.

## One-Click Startup

- **Windows Batch**: Double-click `start-dashboard.bat` in this directory or inside `delhi-aqi-dashboard/`.
- **PowerShell**: Run `.\start-dashboard.ps1`.

The dashboard will open automatically in your browser at `http://localhost:3000`.

For full documentation, please refer to [delhi-aqi-dashboard/README.md](file:///d:/SIH%20PROJECT/delhi-aqi-dashboard/README.md).
